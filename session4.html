원리

HTML 한 장 = 영상 한 편

구조 예시 (읽기만)
<div data-composition-id="main"
     data-width="1080" data-height="1920"
     data-duration="30">
  <section class="clip" data-start="0" data-duration="3">
    훅 문장
  </section>
  <section class="clip" data-start="3" data-duration="12">
    문제 장면
  </section>
</div>
  • 무대 data-width · data-height = 화면 크기. 세로 1080 × 1920, 가로 1920 × 1080
  • 길이 맨 바깥 data-duration = 영상 전체 초
  • 장면 data-start(시작 초) + data-duration(머무는 초)
  • 움직임 GSAP 타임라인 1개 → 시간축에 고정
  • 결과 브라우저 화면 프레임 단위 캡처 → FFmpeg 인코딩 → MP4

장면 연결 : 전환 · 이징 · 타이밍

화면 전환

  • 컷 : 즉시 교체. 기본값
  • 와이프 : 새 장면이 밀고 들어옴
  • 줌 : 확대하며 다음 장면 진입
  • 원칙 : 구간 바뀔 때만 효과

이징 (가속 · 감속)

  • 등장 = 감속 (ease-out) : 빠르게 와서 부드럽게 정지
  • 퇴장 = 가속 (ease-in)
  • 일정한 속도 = 기계적인 느낌

타이밍

  • 한 장면 3 ~ 5초
  • 등장은 짧게, 머무는 시간은 길게
  • 글자 많은 장면 = 읽을 시간 추가
지시 예시
장면 사이 전환은 컷을 기본으로, 문제 → 해결로 넘어갈 때만 와이프 1번. 등장은 모두 감속(ease-out)으로 0.6초.

홍보 영상 브리프
hyperframes 스킬로 내 전자책 홍보 영상을 만들어 줘.
- 목적 : 전자책 「책 제목」 소개, 소개 페이지 방문 유도
- 대상 : 기획서의 독자 한 문장
- 길이 · 비율 : 45초, 세로 9:16 (1080×1920) 먼저
- 톤 : 차분하고 신뢰감 있게, 내레이션 없이 화면 글자 중심
- 재료 : 이 폴더의 표지.png, 사진.jpg
- 핵심 3가지 : 1. … 2. … 3. …
- 핵심 숫자 : 첫 달 7만원 (이 숫자만, 지어내지 말 것)
- 구조 : 훅 → 문제 → 해결 3가지 → 숫자 증거 → 표지 + 링크 안내
스토리보드를 먼저 보여 주고, 렌더는 내가 승인한 뒤에 해 줘.
  • 질문이 오면 하나씩 답하기. 모르면 추천 옵션 번호로 선택
  • 스토리보드 먼저 보기 → 예
  • 진행 방식 자동 진행 vs 함께 만들기 → 오늘은 자동 진행
  • 금지 「알아서 해」 → 검토 단계 생략, 바로 완성으로 직행
  • 결과 폴더에 BRIEF.md 생성 확인

접근성을 보완해 줘. 나머지 디자인은 그대로.
