# 바이브 코딩 4기 강의실 · 클레이 스타일

클레이모피즘 스타일로 재구성한 강의실입니다. 메인 화면, 4개 차시 슬라이드, 예시자료, 결과물 게시판 미리보기로 구성됩니다.

## 실행

```powershell
python -m http.server 8000
```

`http://localhost:8000/index.html`에서 확인할 수 있습니다.

## 범위

- 클레이 스타일 캐릭터 이미지는 이 프로젝트용으로 새로 생성했습니다.
- 원본 사이트의 공개 가능한 강의 문구와 슬라이드 구조를 사용했습니다. 게시 권한은 프로젝트 의뢰자가 확인했습니다.
- 자료실·녹화본은 두온교육 온라인 캠퍼스로 연결되며, 해당 서비스의 수강 권한이 필요할 수 있습니다.
- 수강생 명단, 관리자 기능, 서버 게시판 데이터, 영상 파일은 포함하지 않습니다.
- Zoom·단톡방·출석부의 비공개 접속 주소는 공개 저장소에 넣지 않았습니다.

원본 자료는 두온교육(주)과 해당 권리자에게 귀속됩니다. 별도 허락 없이 다른 용도로 재배포하지 마세요.
